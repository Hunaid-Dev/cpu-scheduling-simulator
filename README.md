# CPU Scheduling Simulator

A menu-driven console program in C++ that simulates CPU scheduling algorithms.

## Features
- FCFS, SJF (non-preemptive), Round Robin, Priority (non-preemptive)
- Text-based Gantt chart
- Waiting time and turnaround time per process, plus averages
- Input validation

## Data Structures Used
- struct: Process
- vector: stores processes and Gantt chart entries
- queue: ready queue for FCFS and Round Robin

## How to Run
g++ main.cpp -o scheduler
./scheduler
